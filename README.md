# Mickey's Merry Christmas Village Collector

A mobile-friendly collection checklist for Mickey's Merry Christmas Village.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new repository**.
2. Give it a name such as `mickey-village-checklist`.
3. Choose **Public** if you want the simplest GitHub Pages setup. The app files/catalog will be public; your collection progress is stored in each browser, not in the repository.
4. Upload **all six files** from this folder to the top level of the repository:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   - `apple-touch-icon.png`
5. In the repository, open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then Save.
8. Wait a minute or two. GitHub will show your published website address in Settings → Pages.

## Add it to your iPhone

1. Open the published GitHub Pages address in **Safari**.
2. Tap the Share icon (square with the up arrow).
3. Scroll and tap **Add to Home Screen**.
4. Tap **Add**.

## Important notes

- Collection ownership, notes, and purchase details are saved in the browser on that device.
- Use the app's **Export backup** option periodically. Keep the JSON backup somewhere safe.
- Clearing Safari website data can erase locally saved collection data. The app does not currently sync between devices.
- The checklist catalog is the working list from the supplied spreadsheet; some catalog entries still carry verification notes in the app.
